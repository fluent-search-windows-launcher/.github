## Troubleshooting Common Issues

Install issues? Rebuild the index if results are missing files that definitely exist.  
Performance problems? Exclude large folders from indexing when memory use climbs.  
License/activation? Check the hotkey for a conflict with another launcher.  
Compatibility? Run as administrator if process actions are blocked.  
Update failures? Update when a Windows release changes file system notifications.
